# Set new log level

Set new log level: "ALL", "DEBUG", "ERROR", "FATAL", "INFO", "OFF",
"TRACE", "WARN"

## Usage

``` r
setLogLevel(level)
```

## Arguments

  - level:
    
    New log level

## Note

setLogLevel since 2.0.0

## Examples

``` r
if (FALSE) { # \dontrun{
setLogLevel("ERROR")
} # }
```
