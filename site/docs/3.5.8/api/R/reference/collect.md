# Collects all the elements of a SparkDataFrame and coerces them into an R data.frame.

Collects all the elements of a SparkDataFrame and coerces them into an R
data.frame.

## Usage

``` r
collect(x, ...)

# S4 method for class 'SparkDataFrame'
collect(x, stringsAsFactors = FALSE)
```

## Arguments

  - x:
    
    a SparkDataFrame.

  - ...:
    
    further arguments to be passed to or from other methods.

  - stringsAsFactors:
    
    (Optional) a logical indicating whether or not string columns should
    be converted to factors. FALSE by default.

## Note

collect since 1.4.0
