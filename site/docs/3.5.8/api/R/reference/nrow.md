# Returns the number of rows in a SparkDataFrame

Returns the number of rows in a SparkDataFrame

## Usage

``` r
# S4 method for class 'SparkDataFrame'
count(x)

# S4 method for class 'SparkDataFrame'
nrow(x)
```

## Arguments

  - x:
    
    a SparkDataFrame.

## Note

count since 1.4.0

nrow since 1.5.0
