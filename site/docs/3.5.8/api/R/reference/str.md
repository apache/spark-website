# Compactly display the structure of a dataset

Display the structure of a SparkDataFrame, including column names,
column types, as well as a a small sample of rows.

## Usage

``` r
# S4 method for class 'SparkDataFrame'
str(object)
```

## Arguments

  - object:
    
    a SparkDataFrame

## Note

str since 1.6.1
