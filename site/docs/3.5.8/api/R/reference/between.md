# between

Test if the column is between the lower bound and upper bound,
inclusive.

## Usage

``` r
between(x, bounds)

# S4 method for class 'Column'
between(x, bounds)
```

## Arguments

  - x:
    
    a Column

  - bounds:
    
    lower and upper bounds

between since 1.5.0
