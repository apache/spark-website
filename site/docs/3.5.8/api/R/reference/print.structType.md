# Print a Spark StructType.

This function prints the contents of a StructType returned from the
SparkR JVM backend.

## Usage

``` r
# S3 method for class 'structType'
print(x, ...)
```

## Arguments

  - x:
    
    A StructType object

  - ...:
    
    further arguments passed to or from other methods

## Note

print.structType since 1.4.0
