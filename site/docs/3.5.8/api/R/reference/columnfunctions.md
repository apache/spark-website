# A set of operations working with SparkDataFrame columns

A set of operations working with SparkDataFrame columns

## Usage

``` r
asc(x)

asc_nulls_first(x)

asc_nulls_last(x)

contains(x, ...)

desc(x)

desc_nulls_first(x)

desc_nulls_last(x)

getField(x, ...)

getItem(x, ...)

isNaN(x)

isNull(x)

isNotNull(x)

like(x, ...)

rlike(x, ...)

ilike(x, ...)
```

## Arguments

  - x:
    
    a Column object.

  - ...:
    
    additional argument(s).
