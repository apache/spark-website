# Get version of Spark on which this application is running

Get version of Spark on which this application is running.

## Usage

``` r
sparkR.version()
```

## Value

a character string of the Spark version

## Note

sparkR.version since 2.0.1

## Examples

``` r
if (FALSE) { # \dontrun{
sparkR.session()
version <- sparkR.version()
} # }
```
