# Print Schema of a SparkDataFrame

Prints out the schema in tree format

## Usage

``` r
printSchema(x)

# S4 method for class 'SparkDataFrame'
printSchema(x)
```

## Arguments

  - x:
    
    A SparkDataFrame

## Note

printSchema since 1.4.0
