# Get the tags that are currently set to be assigned to all the jobs started by this thread.

Get the tags that are currently set to be assigned to all the jobs
started by this thread.

## Usage

``` r
getJobTags()
```

## Note

getJobTags since 3.5.0

## Examples

``` r
if (FALSE) { # \dontrun{
sparkR.session()
tags <- getJobTags()
} # }
```
