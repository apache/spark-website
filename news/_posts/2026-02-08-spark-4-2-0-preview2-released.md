To enable wide-scale community testing of the upcoming Spark 4.2.0 release, the Apache Spark community has posted a
<a href="https://dist.apache.org/repos/dist/release/spark/spark-4.2.0-preview2">Spark 4.2.0-preview2 release</a>.
This preview is not a stable release in terms of either API or functionality, but it is meant to give the community early
access to try the code that will become Spark 4.2.0. If you would like to test the release,
please <a href="https://dist.apache.org/repos/dist/release/spark/spark-4.2.0-preview2">download</a> it, and send feedback using either
<a href="https://spark.apache.org/community.html">mailing lists</a> or
<a href="https://issues.apache.org/jira/browse/SPARK/?selectedTab=com.atlassian.jira.jira-projects-plugin:summary-panel">JIRA</a>.
The documentation is available at the <a href="https://spark.apache.org/docs/4.2.0-preview2/">link</a>.

We'd like to thank our contributors and users for their contributions and early feedback to this release. This release would not have been possible without you.
